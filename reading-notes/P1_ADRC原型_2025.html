A prototype for infrared soldering of electronic devices using the active disturbance rejection control structure

关键词：温度控制（temperature control）；红外光（infrared light）；鲁棒性（robustness）；跟踪（tracking）；时滞系统（delayed systems）

研究摘要

本文研究了将自抗扰控制（Active Disturbance Rejection Control, ADRC）框架应用于红外加热电子焊接系统中的温度跟踪问题。核心思路是不依赖精确数学模型的扰动估计与补偿，直接解决加热过程引入的输入时滞（input delay）带来的控制难题。主要发现如下：

  • 通过一阶Padé 近似（Padé approximation）分析，将输入时滞的影响建模为有界外部扰动，由 ADRC 实时估计并补偿，无需对时滞做多项式近似。
  • 搭建了基于石英卤钨灯（QTH）+ 椭圆金涂层反射镜 + 光学阵列的焊接原型，并对 BGA 器件实现闭环温度控制。
  • 数值仿真与实物实验均验证：ADRC 在跟踪精度上优于经典 PID（Proportional-Integral-Derivative）控制，控制效率指标 ITAEeff（控制效率指数）提升约 12%。
  • 对带损伤焊球的 BGA 器件进行了局部回流返修演示，焊球在表面张力作用下恢复球形几何。
Note

为什么「时滞当作扰动」是聪明的做法：经典控制处理时滞的手段（Smith 预估器、Padé 近似建模）都需要对时滞结构有精确假设。ADRC 的思路是反其道而行——把一切说不清、建不准的东西（时滞、未建模动态、参数漂移）统一归入一个「总扰动」项，再用扩展状态观测器（Extended State Observer, ESO）把它估计出来并在控制律中抵消。只要扰动有界且其导数有界，观测器就能收敛。这正是 ADRC 在工业场合（尤其像焊接这种模型难精确、工况多变的过程）受欢迎的根本原因。

1. 引言

电子电路板上的元器件按安装技术分为通孔技术（Through-Hole Technology, THT）与表面贴装技术（Surface-Mount Technology, SMT）两类。可靠的焊点需要三种要素：助焊剂（清洁表面）、焊料（填充接头）与热量（熔化焊料）。焊接的关键在于精确跟踪温度曲线——温度与时间的关系，两种基本类型为 RSS 曲线（Ramp-Soak-Spike，升温-保温-峰值）与线性斜坡曲线（图 4）。偏离器件制造商规定的温度曲线会引发冷焊、桥连、立碑（tomb-stoning）、焊球损伤、焊盘剥离等一系列缺陷。

现代电子制造依赖紧凑、自动化、节能的 SMT 回流焊系统，红外辐射（infrared radiation, IR）与强制对流是两种主流传热机制。近红外（NIR）辐射可实现局部与选择性加热，适合 PET 等热敏/低成本基板；QTH 灯配合光学布置可将红外辐射聚焦到特定器件上。但这些系统的共同局限是缺乏闭环控制方案来跟踪预设温度曲线，导致热不均匀、焊球成形不良等问题。工业红外炉加热快且无接触，但性能对材料发射率与几何形状敏感，陶瓷基板上红外加热会产生显著热梯度；混合 IR-对流系统则兼顾了快速加热与温度均匀性。

热控制还与材料表征和温度均匀性相关：PBGA 封装在过模材料超过玻璃化转变温度（约 170 °C）时会发生过大翘曲导致断路或短路；红外炉内表面发射率变化与遮挡效应可造成基板内高达 10 °C 的梯度。先进的热建模与智能控制（三维瞬态热模型、模糊逻辑实时温控等）已被用于提升回流工艺的精度与可重复性。

本文提出将 ADRC 控制结构用于红外光 + 光学阵列加热的电子器件焊接曲线跟踪。该问题的难点在于：缺乏精确的被控对象模型、存在时滞与未建模动态。处理传输时滞的两类经典方法——Smith 预估器与 Padé 近似——已被与 PID、模糊、滑模、内模控制等多种算法结合，ADRC 亦是其中之一。本文的假设是：将输入时滞视为有界外部扰动，利用 ADRC 的扰动估计能力进行补偿，从而避免对时滞做多项式近似，获得更优的闭环性能。图 1 给出了本文的组织结构。

Note

RSS 温度曲线为什么是四段式：预热段（线性升温至保温温度）让焊料与器件均匀受热、挥发助焊剂溶剂；保温段（恒温）均衡整板温度、防止热冲击；回流段（快速升至峰值）使焊料熔化并润湿焊盘形成金属间化合物；冷却段（受控降温）让焊点固化而避免热冲击产生裂纹。峰值温度与「液相线以上时间」（TAL）是决定焊点可靠性的两个核心工艺参数——峰值过高会损伤器件，TAL 过短则金属间化合物层过薄。

2. 原型系统描述

原型的第一部分是石英钨卤灯（Quartz Tungsten Halogen, QTH）白炽灯，集成了椭圆金涂层反射镜。反射镜利用椭圆几何特性将辐射汇聚到第二焦点，实现能量集中。灯泡电功率 150 W（15 V、10 A），通过调节电功率可调制光输出功率，焦点处温度最高可达 1200 °C。光学系统由准直透镜（捕获并准直辐射）与聚焦透镜（调节红外光束直径、精确递送能量到目标器件）组成，整体光学布置见图 2。

加热目标为球栅阵列（Ball Grid Array, BGA）器件——焊球呈阵列分布在器件一侧的 SMT 封装，尺寸 5 mm × 6 mm。部分焊球存在损伤缺陷，这正是电子焊接行业需要解决的问题之一。J 型热电偶直接接触 BGA 表面监测热曲线，配合 NI cRIO-9074 实时控制器（LabVIEW 实现控制算法）与自制功率放大器构成闭环：热电偶 → 数据采集 → 实时控制 → 功放 → 红外光源，如图 3 所示。

3. 建模与参数辨识

3.1 红外加热机理

系统温升源于石英卤钨灯红外辐射的吸收。光源辐射输出强烈依赖其工作温度，遵循 Stefan–Boltzmann 定律（斯特藩-玻尔兹曼定律）$P = \epsilon \sigma A T^{4}$（ε 为发射率，σ 为斯特藩-玻尔兹曼常数，A 为发射面积）。对 BGA 器件而言，红外辐射主要在暴露的金属区域与焊球表面被吸收；由于材料热导率高、焊球特征尺寸小，吸收的热量在体积内快速再分布，短暂瞬态后温度场近似均匀——这为下一节的集总热容模型提供了依据。

3.2 集总参数热模型

采用集总热容（lumped-capacitance）能量平衡描述温度演化，假设加热区域温度空间均匀。该近似适用于小尺寸、高导热的物体（如 BGA 与焊球区域），其毕渥数（Biot number）$Bi = hL_c/k$ 低于 0.1 即可成立。热动态满足：

$$ m c _ { p } \frac { d T ( t ) } { d t } = q _ { \mathrm { in } } ( t ) - h A ( T ( t ) - T _ { \infty } ) \tag{1} $$

解读：这是经典的一阶热平衡方程——左侧是热惯性（质量 m × 比热容 cp × 温升速率），右侧第一项是吸收的辐射功率（输入），第二项是与环境（温度 T∞）的对流/辐射热交换（h 为综合换热系数，A 为换热面积）。它把复杂传热问题压缩成一个一阶微分方程。

假设加热区间输入功率近似恒定，方程 (1) 的解为：

$$ T ( t ) = T _ { \infty } + ( T _ { 0 } - T _ { \infty } ) e ^ { - t / \tau _ { \mathrm { th } } } , \qquad \tau _ { \mathrm { th } } = \frac { m c _ { p } } { h A } \tag{2} $$

解读：温度以指数形式趋近稳态，热时间常数（thermal time constant）τth = mcp/(hA) 决定趋近快慢：经过一个 τth，输出达到终值的约 63%。τth 越大，系统惯性越大、响应越慢——这是后续控制设计中需要补偿的主导动态。

3.3 基于实验的系统建模

对系统施加幅值 3 V 的阶跃输入信号，响应表现出典型一阶系统特征，但起始阶段存在约 1.603 s 的时滞（图 5）。使用 MATLAB System Identification Toolbox 辨识得到传递函数：

$$ F ( s ) = \frac { b } { s + a } e ^ { - \tau s } \tag{3} $$

解读：a = 0.094339、b = 4.4838、τ = 1.603。这是一阶惯性环节 + 纯时滞（transport delay）的标准形式，e−τs 即输入时滞的频域表达。时滞来自加热过程的物理环节（热传递与传感延迟）。

图 6 对比了实验温度输出（黑线）与数值温度输出（红线），验证模型 (3) 的准确性。

对时滞项 e−τs 有多种多项式近似，最常用之一是一阶 Padé 近似：

$$ e ^ { - \tau s } \approx \frac { 2 - \tau s } { 2 + \tau s } \tag{4} $$

解读：Padé 近似用有理函数逼近超越函数 e−τs，一阶形式分子含零点 −2/τ（右半平面零点），这使近似后的系统成为非最小相位系统（non-minimum phase system）。

将其代入传递函数 (3) 得：

$$ F ( s ) \approx \frac { - b s + \frac { 2 b } { \tau } } { s ^ { 2 } + \frac { a \tau + 2 } { \tau } s + \frac { 2 a } { \tau } } \tag{5} $$

解读：一阶时滞系统经 Padé 近似后变成二阶系统，分子含负系数项 −bs（右半平面零点），阶数抬升一阶——这正是经典「用近似换模型复杂度」的代价。

其状态空间表示为：

$$ \begin{aligned} \dot { x } _ { 1 } ( t ) & = - \frac { 2 a } { \tau } x _ { 2 } ( t ) + \frac { 2 b } { \tau } u ( t ) , \\ \dot { x } _ { 2 } ( t ) & = x _ { 1 } ( t ) - \frac { a \tau + 2 } { \tau } x _ { 2 } ( t ) - b u ( t ) , \\ y ( t ) & = x _ { 2 } ( t ) . \end{aligned} \tag{6} $$

解读：该系统的输出 y = x2 的动态受到一个人为引入的辅助状态 x1 影响——这个 x1 与真实物理无关，纯粹来自时滞近似，可以视为一种外部扰动。

因此本文采用系统 (3) 的最简近似：

$$ \begin{aligned} \dot { x } ( t ) & = - a x ( t ) + b u ( t ) + \gamma ( \cdot ) , \\ y ( t ) & = x ( t ) , \end{aligned} \tag{7} $$

解读：把时滞的影响全部打包进「扰动项」γ(·)，并假设 |γ(·)| < δ0、|γ̇(·)| < δ1（有界且导数有界）。这就是本文的核心思想——不建时滞的近似模型，而是把时滞当成扰动交给 ADRC 去估计。实验测得的时间常数（63% 上升准则，补偿时滞后）与辨识值 τth = 1/a = 10.61 s 吻合，验证了热模型与参数的有效性。

Note

非最小相位与扰动建模的工程直觉：直接接触焊料表面的热电偶因自身热容与接触热阻会引入微小动态滞后；传感器位于器件表面而非红外光束焦点，快速瞬态时还会出现轻微空间温度偏差——这些效应都会「阻尼并延迟」实测响应，但不会改变系统主导的一阶热行为。换言之，实验中观察到的时间常数与模型参数相互印证，而建模误差与上述未建模动态恰好都落进了 ADRC 的「总扰动」口袋里，这正是该方法对模型不精确性鲁棒的来源。

4. ADRC 控制策略设计与实现

4.1 控制目标与理想控制律

控制目标是设计控制输入 u(t)，使系统输出跟踪参考信号 yr(t)（其导数为常数，即斜坡类参考）：

$$ \lim _ { t \to \infty } | y ( t ) - y _ { r } ( t ) | = 0 \tag{8} $$

解读：焊接工艺要求输出温度精确跟踪预设温度曲线，因此这是一个轨迹跟踪（trajectory tracking）问题，而非简单的镇定问题。

定义误差变量 e(t) = y(t) − yr(t)，其动态为：

$$ \dot { e } ( t ) = - a e ( t ) - a y _ { r } ( t ) - \dot { y } _ { r } ( t ) + \gamma ( \cdot ) + b u ( t ) \tag{9} $$

解读：误差动态中除自身项 −ae 外，还混入了参考信号项、扰动 γ 与控制输入项——控制律的设计目标就是把后三者抵消掉。

理想控制律为：

$$ u ( t ) = \frac { 1 } { b } \left( a y _ { r } ( t ) + \dot { y } _ { r } ( t ) - \gamma ( \cdot ) - k e ( t ) \right) \tag{10} $$

解读：这是标准的「模型抵消 + 比例反馈」形式：前馈项 a yr + ẏr 处理参考轨迹，−γ 抵消扰动，−ke 提供误差收敛（k 为控制器增益）。若扰动已知，代入 (9) 得：

$$ \dot { e } ( t ) = - ( a + k ) e ( t ) \tag{11} $$

解读：选择足够大的 k 即可使误差原点全局指数稳定。但 γ(t) 未知，控制律 (10) 无法直接实现——下一步用扩展状态观测器在线估计 γ。

4.2 扩展状态观测器

扰动 γ(·) 不可测，用扩展状态观测器估计。针对被控对象 (7)，所提出的观测器为：

$$ \dot { \hat { x } } ( t ) = - a \hat { x } ( t ) + b u ( t ) + c _ { 1 } ( y ( t ) - \hat { y } ( t ) ) + w ( t ) \tag{12} $$

解读：x̂ 是状态的估计，w 是扰动 γ 的估计（「扩展状态」）。观测器结构与对象 (7) 相同，外加两个修正项：比例修正 c1(y − ŷ) 与估计的扰动 w。

$$ \begin{aligned} \dot { w } ( t ) & = c _ { 2 } ( y ( t ) - \hat { y } ( t ) ) + c _ { 3 } \operatorname { s i g n } ( y ( t ) - \hat { y } ( t ) ) , \\ \hat { y } ( t ) & = \hat { x } ( t ) . \end{aligned} \tag{13} $$

解读：扰动估计 w 的更新律含两项：线性积分项 c2·(y−ŷ) 与滑模项（sliding mode term）c3·sign(y−ŷ)。sign 项带来强鲁棒性，也引入不连续面，形成二阶滑模动态。

定义观测误差 ε(t) = x(t) − x̂(t)，其动态为：

$$ \begin{aligned} \dot { \epsilon } ( t ) & = \gamma ( \cdot ) - ( c _ { 1 } + a ) \epsilon ( t ) - w ( t ) , \\ \dot { w } ( t ) & = c _ { 2 } \epsilon ( t ) + c _ { 3 } \operatorname { s i g n } ( \epsilon ( t ) ) . \end{aligned} \tag{14} $$

解读：误差动态中，扰动 γ 与观测器增益、滑模项共同作用。做变量代换 η1(t) = ε(t)、η2(t) = γ(·) − (c1+a)ε(t) − w(t)，得：

$$ \begin{aligned} \dot { \eta } _ { 1 } ( t ) & = \eta _ { 2 } ( t ) , \\ \dot { \eta } _ { 2 } ( t ) & = - c _ { 2 } \eta _ { 1 } ( t ) - ( c _ { 1 } + a ) \eta _ { 2 } ( t ) - c _ { 3 } \operatorname { s i g n } ( \eta _ { 1 } ( t ) ) + \dot { \gamma } ( \cdot ) . \end{aligned} \tag{15} $$

解读：变换后系统呈标准二阶形式：η̇1 = η2（积分链），η2 动态含线性反馈与滑模项。γ̇(·) 有界（|γ̇| < δ1）保证稳定性分析成立。

定义矩阵 A 与 Lyapunov 方程 ATP + PA = −I 的解 P：

$$ A = \begin{bmatrix} 0 & 1 \\ - c _ { 2 } & - ( c _ { 1 } + a ) \end{bmatrix} \tag{16} $$

解读：A 是观测器误差系统的线性部分矩阵，其特征值由增益 c1、c2 决定。

$$ P = \begin{bmatrix} p _ { 1 1 } & p _ { 1 2 } \\ p _ { 1 2 } & p _ { 2 2 } \end{bmatrix} \tag{17} $$

解读：P 为 Lyapunov 方程 ATP + PA = −I 的正定解，用于构造 Lyapunov 函数 V = ηTPη 并推导滑模增益 c3 的充分条件。

依据文献 [27] 的定理 1，可证明：

$$ c _ { 3 } > 2 \lambda _ { \mathrm { m a x } } ( P ) \sqrt { \frac { \lambda _ { \mathrm { m a x } } ( P ) } { \lambda _ { \mathrm { m i n } } ( P ) } } \left( \frac { c _ { 2 } \delta _ { 1 } } { \sigma } \right) \tag{18} $$

解读：定理 1（原文）：对系统 (14)，若 c3 满足上式（对某个 0 < σ < 1），则原点 (η1=0, η2=0) 在 Lyapunov 意义下全局渐近稳定。λmax/λmin 为 P 的最大/最小特征值——这是选择滑模增益 c3 的工程准则。

系统 (14) 在 η1(t) = 0 处存在不连续面，c3·sign(η1) 产生二阶滑模（second-order sliding mode），即等效控制出现在定义不连续面的函数的二阶时间导数中：

$$ \ddot { \eta } _ { 1 } ( t ) = - c _ { 2 } \eta _ { 1 } ( t ) - ( c _ { 1 } + a ) \eta _ { 2 } ( t ) - u _ { \mathrm { e q } } ( \cdot ) + \dot { \gamma } ( \cdot ) = 0 \tag{19} $$

解读：滑模面上 η̈1 = 0，由此可解出等效控制（equivalent control）——即滑模面上使系统维持滑动所需的「平均」控制作用。

$$ u _ { \mathrm { e q } } ( \cdot ) = \dot { \gamma } ( \cdot ) \tag{20} $$

解读：等效控制恰等于扰动导数——这从机理上说明观测器的滑模通道在「追踪」扰动的变化率。

$$ w ( t ) = \gamma ( \cdot ) \tag{21} $$

解读：由等效控制关系反推，在滑模面上观测误差为零且扰动估计 w 精确等于真实扰动 γ——观测器实现了对扰动的在线重构。

最终控制律 (10) 取如下可实现形式：

$$ u ( t ) = \frac { 1 } { b } \left( a y _ { r } ( t ) + \dot { y } _ { r } ( t ) - w ( t ) - k e ( t ) \right) \tag{22} $$

解读：把理想控制律 (10) 中未知的 γ 换成观测器估计 w——「估计扰动、实时补偿」闭环形成：观测器（内环）估计扰动 → 控制器（外环）利用估计值抵消扰动。

Note

扩展状态观测器的本质：ESO 把一个「一阶对象 + 未知扰动」的辨识问题转化为一个二阶观测器的增益设计问题。对象阶数越高，ESO 阶数也相应提高（n 阶对象配 n+1 阶 ESO）。这里 sign 项带来的二阶滑模比普通线性 ESO 更强的原因是：线性 ESO 只能保证扰动估计误差有界收敛到 O(1/c3) 的邻域，而滑模 ESO 在理论上可精确重构扰动（等效控制原理），这对含时滞的焊接过程尤为重要——因为时滞扰动的导数可能较大，线性观测器带宽不够时估计会明显滞后。

4.3 稳定性分析

重要性质：观测器性能与控制器输入无关，凭借其鲁棒性与收敛性可应用分离原理（separation principle）——即观测器与控制器可独立设计。将 (22) 代入 (9) 得：

$$ \dot { e } ( t ) = - ( a + k ) e ( t ) + \gamma ( \cdot ) - w ( t ) \tag{23} $$

解读：闭环误差动态 = 稳定线性项 −(a+k)e + 扰动估计残差 γ − w。若观测器收敛（w → γ），残差趋于零，闭环稳定。

理想情况下：

$$ \lim _ { t \to \infty } w ( t ) = \gamma ( \cdot ) \tag{24} $$

解读：γ(·) − w(t) 可视为渐消扰动（vanishing disturbance）；若满足文献 [28] 中的线性增长界，原点成为渐近稳定平衡点。

实际工程中可实现的最佳状态是估计残差有界：

$$ \lim _ { t \to \infty } | \gamma ( \cdot ) - w ( t ) | \leqslant \epsilon \tag{25} $$

解读：对非渐消扰动（non-vanishing disturbance），系统轨迹收敛到原点的小邻域内，输出保持贴近参考——这给出了实际闭环性能的界。

Note

分离原理为什么重要：它把「观测器增益（c1, c2, c3）」与「控制器增益（k）」两组参数的整定解耦——可以先按扰动收敛速度调观测器，再按跟踪性能调控制器，互不干扰。这在工程调试上极其友好，也是 ADRC 参数整定比传统 PID 更直观的原因之一（PID 的 P/I/D 三项耦合，整定常需反复试凑）。

5. 闭环系统性能分析

分别在数值仿真与实物实验中对比经典 PID 与 ADRC 的跟踪性能。PID 是工业过程中（含时滞过程）使用最广泛的控制器，作为比较基准最合适。仿真在 LabVIEW 上用固定步长 Euler 求解器（步长 0.001 s）完成，实验在 NI cRIO-9074 实时平台上进行。

5.1 数值仿真结果

经典 PID 控制器形式为：

$$ u ( t ) = k _ { p } e ( t ) + k _ { i } \int e ( t ) d t + k _ { d } \frac { d e ( t ) } { d t } \tag{26} $$

解读：用自整定算法选取增益 kp = 0.05099、ki = 0.00361、kd = 0.120288。PID 的三个通道分别处理当前误差、历史误差累积（消除稳态偏差）、误差变化率（抑制超调）。

PID 仿真结果（图 7）：输出（红线）不振荡，但大部分时间存在显著误差——参考信号第一阶段约 17 °C、最高温处约 22 °C，对焊接工艺而言误差过大。控制输入 u(t) 保持在 0–10 V（功放工作范围）内。

ADRC 仿真（图 8）：观测器增益 c1 = 200、c2 = 50、c3 = 70，控制器增益 k = 0.5。稳态误差几乎消除，但参考最高温处存在约 10 °C 超调。图 9 显示观测器性能接近理想：扰动 w(t) 被准确估计，可用于可靠的在线补偿。结论：数值仿真背景下 ADRC 结构优于 PID。

Note

仿真中 PID 与 ADRC 误差特征的对比解读：PID 在含时滞系统中本质上是「先看到偏差再反应」——时滞使偏差信息晚到，比例项被迫加大增益弥补相位损失，但增益过大会振荡，因此 PID 只能在高增益与稳态误差之间折中。ADRC 的观测器则在时滞作用生效前就「预测」到扰动并前馈补偿，相当于把时滞环节从控制回路中"隔离"出来——这是仿真中 ADRC 稳态误差近零而 PID 高达 17–22 °C 的机理原因。ADRC 的代价是参考最高温处约 10 °C 超调（观测器暂态估计误差所致），但该超调对焊接工艺而言远优于持续的大偏差。

5.2 实验结果

实验中因仿真增益下跟踪误差显著，PID 增益重新整定为 kp = 0.5、ki = 0.2、kd = 0.2。闭环性能见图 10：输出（红线）在参考信号起始阶段出现振荡；稳态误差先减后增，最高温度处误差约 20 °C；控制输入在实验开始阶段振荡显著。

ADRC 实验（图 11）：观测器参数不变，控制器增益调为 k = 0.9。输出几乎全程存在小幅振荡但均值贴近参考；关键结果是最高温度处误差仅约 4 °C（远优于 PID 的 20 °C）。控制信号持续振荡但频率低于 PID 情形。

两种控制器都出现的振荡是含时滞系统的典型现象，对焊接工艺不构成问题——关键判据是参考结束阶段能否达到最高温度。由此可得出结论：ADRC 控制器在不要求复杂对象模型的情况下优于 PID 控制器。

为从能量效率角度评估整体性能，引入控制效率指标 ITAEeff，定义为时间加权绝对误差积分（ITAE）与总控制能量（Eu）之比：

$$ I T A E _ { \mathrm { e f f } } = \frac { I T A E } { E _ { u } } \tag{27} $$

解读：该指标量化控制器「用每单位执行机构能量换取多少跟踪误差削减」的能力，数值越低表示控制效率越高。

$$ I T A E = T _ { s } ^ { 2 } \sum _ { k = 1 } ^ { N } k \left| y _ { r } ( k ) - y ( k ) \right| \tag{28} $$

解读：ITAE 对误差按时间加权（k 为采样序号，Ts 为采样周期）——后期误差的惩罚重于早期误差，适合评估长期跟踪质量。

$$ E _ { u } = \sum _ { k = 1 } ^ { N } u ( k ) ^ { 2 } \tag{29} $$

解读：Eu 为控制输入平方和，衡量执行机构消耗的能量；N 为实验采样总数。

6. 应用示例：BGA 局部返修

为展示实际应用，对带损伤焊球的 BGA 器件执行局部加热工艺。图 12 展示了多个受损焊球（红色标注）——半扁平或不规则形貌是制造中的常见失效模式（贴装时表面张力过大或搬运设备机械应力所致），此类器件常被直接报废，造成材料浪费与成本上升。

按标准无铅回流温度曲线执行局部回流：预热至约 150 °C，保温区接近 180 °C，峰值 244 °C ± 2 °C，液相线以上时间（TAL）58 s。焊料达到熔点后，表面张力成为主导力——为最小化表面能而恢复焊球的球形几何；焊料的黏聚与弹性特性促进焊球快速自重构。处理后的器件见图 13：焊点恢复了规则、均匀的球形。

Note

「表面张力自修复」的物理机制：熔融焊料是液滴系统，表面张力驱动其趋向最小表面积形态——球体正是给定体积下表面积最小的几何体。因此只要焊球被充分熔化（峰值温度与 TAL 达标）且未被氧化（助焊剂作用），球形几何就会「自动」恢复。该演示证明：光学约束 + 闭环温控使热量只作用于目标区域，避免整板受热，实现了选择性返修——从可持续性角度看，可修复本应报废的器件、减少电子废弃物。未来工作将包括剪切测试、切片分析与 X 射线检查等机械可靠性验证。

7. 结论

  1. ADRC 结构能有效解决控制输入含时滞系统的跟踪问题，且无需对时滞做任何多项式近似——时滞效应被当作外部扰动，由 ADRC 实时估计与补偿。
  2. 数值仿真的精度优于实验结果，但实验仍确认 ADRC 闭环系统优于传统 PID，优势源于其对未建模动态与外部扰动的主动估计。
  3. ADRC 的控制信号略为多变（振荡），但跟踪精度与控制能量之间的权衡明显更优：以更少的相对控制能量实现了更贴近期望热曲线的温度响应，红外温度调节的整体控制效率更高。
  4. 在原型上的应用展示表明，ADRC 有助于提升工业焊接工艺，为降低能耗与减少电子电路废弃物提供了可行路径。

核心要点总结

  1. 「时滞即扰动」范式：输入时滞经一阶 Padé 分析后，其影响被归并为有界外部扰动 γ(·)，由 ESO 在线估计并补偿——这是全文方法论的基石，避免了 Smith 预估器/高阶 Padé 等复杂时滞建模。
  2. 硬件方案：150 W QTH 灯 + 椭圆金反射镜 + 双透镜光学阵列，实现焦点温度最高 1200 °C 的局部聚焦加热；NI cRIO-9074 实时平台闭环控制 BGA 温度。
  3. 模型：一阶惯性 + 纯时滞 F(s) = (b/(s+a))e−τs，a = 0.094339、b = 4.4838、τ = 1.603 s；热时间常数 τth = 10.61 s 与实验 63% 准则吻合。
  4. 控制律：u = (1/b)(ayr + ẏr − w − ke)，观测器增益 c1 = 200、c2 = 50、c3 = 70，控制器增益 k = 0.5（仿真）/ 0.9（实验）；分离原理保证观测器与控制器独立整定。
  5. 性能对比：仿真中 PID 误差 17–22 °C 而 ADRC 稳态误差近零（仅最高温处约 10 °C 超调）；实验中最高温误差 PID 约 20 °C vs ADRC 约 4 °C。
  6. 效率指标：ITAEeff 由 123.74（PID）降至 108.62（ADRC），提升约 12.2%——同等控制能量下跟踪更准。
  7. 应用价值：BGA 局部返修演示（峰值 244 °C ± 2 °C，TAL 58 s）成功修复受损焊球，展示选择性返修与减少电子废弃物的可持续路径。
